# Project Question | سؤال المشروع

## بالعربي

صمّم مساعدًا ذكيًا بسيطًا لرفع الإنتاجية في بيئة العمل باستخدام أحد أدوات الذكاء الاصطناعي التوليدي مثل Claude أو ChatGPT أو Gemini.

المساعد يجب أن يحل مشكلة عملية واحدة، ويحوّل مدخلات غير منظمة إلى مخرجات واضحة قابلة للاستخدام.

## English

Design a simple AI productivity assistant using a generative AI tool such as Claude, ChatGPT, or Gemini.

The assistant should solve one practical workplace problem and turn unstructured input into clear, usable output.

---

## Required Deliverables | المتطلبات

1. Project name
2. Problem statement
3. Target users: who will use this assistant or (prompts).
4. R-C-T-F prompt: one prompt ( a strong prompt ).
5. Sample input: two different inputs.
6. Sample output: one output per input.
7. Safety checklist: at least 3 checks.
8. Reflection

---
