# GenAI Productivity Assistant – Final Individual Project

## نبذة عن المشروع

هذا مشروع فردي لمدة **60 دقيقة** ضمن برنامج **Generative AI for Productivity** التابع لأكادمية سدايا. 
الهدف هو أن يطبق المتدرب ما تعلمه خلال اليومين السابقين: كتابة Prompt واضح، استخدام أدوات الذكاء الاصطناعي لرفع الإنتاجية، تنظيم المخرجات، وتطبيق قواعد السلامة والتحقق.

This is an individual 60-minute project for the **Generative AI for Productivity** program.  
The goal is to apply the skills learned in the previous two days: structured prompting, productivity use cases, organized outputs, and safe AI use.

## سؤال المشروع

صمّم مساعدًا ذكيًا بسيطًا لرفع الإنتاجية في بيئة العمل باستخدام أحد أدوات الذكاء الاصطناعي التوليدي مثل Claude أو ChatGPT أو Gemini.

يجب أن ينجز المساعد مهمة عملية واحدة بوضوح، مثل:
- تلخيص اجتماع
- تحسين بريد إلكتروني
- تحليل ملاحظات تقييم
- إنشاء قائمة تحقق
- تنظيم خطة تدريب
- تحويل معلومات غير مرتبة إلى مخرجات منظمة

يجب أن يحتوي مشروعك على:
1. فكرة المشروع والهدف منه.
2. المشكلة التي يحلها.
3. Prompt منظم باستخدام R-C-T-F.
4. مثال Input.
5. مثال Output.
6. Safety Checklist.
7. Reflection قصيرة: ماذا تعلمت؟ وما الذي ستطوره لاحقًا؟

## Project Question

Design a simple AI productivity assistant using a generative AI tool such as Claude, ChatGPT, or Gemini.

Your assistant should complete one practical workplace task clearly, such as:
- Summarizing a meeting
- Improving an email
- Analyzing feedback
- Creating a checklist
- Organizing a training plan
- Turning messy information into structured output

Your project must include:
1. Project idea and goal.
2. The problem it solves.
3. A structured R-C-T-F prompt.
4. Sample input.
5. Sample output.
6. Safety checklist.
7. Short reflection: what you learned and what you would improve next.

---

## اختر فكرة واحدة من الأفكار التالية

### 1. Meeting Follow-up Assistant
مساعد يحول ملاحظات اجتماع غير مرتبة إلى ملخص، قرارات، مهام، أسئلة مفتوحة، وبريد متابعة.

### 2. Training Feedback Analyzer
مساعد يحلل تعليقات المتدربين ويستخرج أهم 5 themes مع توصيات عملية.

### 3. Email Polisher Assistant
مساعد يحول رسالة غير رسمية إلى بريد مهني واضح بثلاث نبرات مختلفة.

### 4. Course Design Assistant
مساعد يصمم جلسة تدريبية قصيرة تشمل أهداف التعلم، جدول الجلسة، تمرين عملي، وأسئلة تقييم.

### 5. Onboarding Checklist Assistant
مساعد ينشئ قائمة تحقق لموظف جديد خلال أول أسبوع في العمل.

### 6. Safe AI Use Checklist Assistant
مساعد ينشئ دليلًا مختصرًا لاستخدام أدوات الذكاء الاصطناعي بأمان داخل العمل.
