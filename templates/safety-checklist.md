# Safety Checklist

Before using AI, check:

- No personal data is included.
- No confidential company data is included.
- No passwords, API keys, IDs, or tokens are included.
- The output is reviewed by a human.
- Facts, numbers, names, and dates are verified.
- Missing information is marked as TBD.
- AI is used to assist, not to make the final decision alone.
- If using connectors, send/delete/share actions require approval.
