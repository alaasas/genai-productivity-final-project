# Prompt Template

## Copy and edit this prompt

```text
Role:
You are a professional [assistant type].

Context:
I am working on [workplace task]. The input may be messy or incomplete.

Task:
Analyze the input and create a clear, useful output.

Format:
Return the answer using this structure:
1. Summary
2. Key points
3. Action items
4. Missing information
5. Final draft / checklist / table

Rules:
- Use only the provided information.
- Mark missing information as TBD.
- Do not invent names, dates, numbers, or decisions.
- Keep the output professional and concise.
- Highlight anything that needs human review.
```
